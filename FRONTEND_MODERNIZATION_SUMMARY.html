Backend Compatibility

✓ No backend changes required. The frontend modernization is 100% compatible with the existing FastAPI backend. All API calls remain unchanged:

API Endpoints (Unchanged)

  • GET /health — Health check (used for API Status badge)
  • GET /intents — Intent taxonomy (mapped to display names)
  • POST /chat — Chat query (returns intent, confidence, sources)
  • POST /reset — Memory reset (unchanged)

Chat Data Structure (Unchanged)

The response structure from the backend remains identical. The frontend simply applies display name mapping to the returned detected_intent field.

Backend returns: {"detected_intent": "orders", ...}
Frontend displays: "Orders" (via mapping)
